在 Fabric Carpet 环境中提供玩家假人相关功能。

## 工程结构

可构建项目位于 [fabric/1.21.6/](fabric/1.21.6/)。仓库共享元数据保留在根目录。

## 构建

请进入目标目录并运行 Gradle Wrapper。

Windows PowerShell：

```powershell
cd fabric/1.21.6
.\gradlew.bat clean build
```

Linux/macOS：

```sh
cd fabric/1.21.6
./gradlew clean build
```
